## 📖 About

Arcanity is a mod that adds a new enchanting workbench, multi-tool, and a handful of convenient enchantments.

## ✨ Arcane Table

The Arcane Table allows for a more convenient path to obtaining your desired enchantments. It does this by allowing you to pick which enchantments to unlock on your gear. These enchantments will slowly become unlocked as you earn experience.

To obtain an Arcane Table, head to The Nether and raid a Bastion Remnant. You can also duplicate the Arcane Table by combining it with a [Crafting Table](https://minecraft.wiki/w/crafting_table).

## ⛏️ Arcane Tool

The Arcane Tool is a new tool that functions as a weapon, shovel, pickaxe, and axe. This means you can save inventory space by carrying just one tool instead of several. It deals the same amount of damage as a Netherite Sword and mines just as fast as a Netherite Pickaxe.

Right-clicking with the Arcane Tool allows you to strip wood, scrape oxidized blocks, and till farmland. Alternatively, you can create path blocks by shift-right-clicking on dirt blocks.

## 📙 Enchantments

Arcanity adds 5 new enchantments that are only obtainable in the Arcane Table.

**Abundance** - An Arcane Tool specific enchantment that gives a chance to receive more item drops from blocks and mobs, similar to [Fortune](https://minecraft.wiki/w/Fortune) and [Looting](https://minecraft.wiki/w/Looting).

**Blaze** - A tool enchantment that smelts drops from mined blocks and ignites entities when hit with melee attacks, similar to [Fire Aspect](https://minecraft.wiki/w/Fire_Aspect).

**Collect** - An enchantment that can be applied to any weapon or tool to allow for drops to be instantly inserted into your inventory.

**Excavate** - A tool enchantment that allows mining in a 3x3 area.

**Vein Mining** - A tool enchantment that allows mining neighboring blocks of the same type.
